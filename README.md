# Data-Visualization-Task-2
This is the Task 2(Data Visualization) of my Data Analyst Internship with Elevate labs.

## Sales Dashboard – Power BI

- Created an interactive Superstore Sales Dashboard using Power BI.
- Developed KPI cards to display Total Sales, Total Profit, Total Orders and Profit Margin.
- Used line charts to visualize monthly sales trends from January to December.
- Created bar charts to analyze sales across different product categories.
- Visualized regional sales performance across West, East, Central and South regions.
- Added a customer-level table displaying Customer Name, Sales and Profit.
- Implemented a Customer Segment slicer to filter dashboard data dynamically.
- Applied interactive filtering to analyze sales and profit across different segments.
- Customized chart formatting, labels and layouts for better readability.
- Analyzed overall business performance through interactive visualizations.
